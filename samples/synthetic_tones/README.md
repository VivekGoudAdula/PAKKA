# Synthetic Audio Samples (Sine-Wave Test Tones)

> [!WARNING]
> **NOT SPEECH AUDIO**: The `.wav` files in this directory are purely synthetic mathematical sine-wave tones (8000 Hz, 16-bit linear PCM) overlaid with Gaussian white noise.
> They are **NOT** human voice recordings, and they are **NOT** speech generated by Gnani Timbre or any TTS engine.

## Purpose

These files were generated locally by `scripts/make_test_audio.py` for a single purpose:
- To test the byte-level rechunking logic (`Rechunker(frame_size=1024)`) and energy VAD frame processing under simulated SNR degradation (Clean, 15 dB, 5 dB).
- They must **never** be presented in any user interface, audio player, or evaluation report as actual speech audio or spoken Hindi/Hinglish dialog.
